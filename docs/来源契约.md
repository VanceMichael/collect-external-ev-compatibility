# 资料提供方的格式

`/supplier/releases.html` 行给组件、版本标签、构建、配对用途、包号。 `/supplier/withdraw.json` 精确到包、车系和模式。 `/bench/boots.csv` 是开机/刷入记录，boot 是同一启动上下文，mode 是测试用途，power 是台架环境简称。 `/bench/blocks.json` 行给开机、测试项、签认的构建以及结果；result 来源于该次独立试验，不能覆盖其他启动。
`/dispatch/requests.json` 为待复测车系、实体终端及组合条件。 `/dispatch/stands.json` 是工位条件与现有领用，具体分钟仅为演练时钟。
`/bench/follow-up.json` 是后来取得的一次独立补测，dispatch 把工作单与新开机证据相连。
开机记录最后一列 paired 是台架实际配对件。复测请求的 configuration 提供申请编号对应的配对件和固件构建。补测开机记录沿用台架字段顺序。
